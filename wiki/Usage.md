# Usage

Select Full GitHub in a Codex chat opened in your project.

## Audit

Ask to audit every capability. The agent reads repository rules, discovers the actual host/owner, builds a complete coverage ledger, performs configuration probes and follows up with object-level API/UI reads. Unknown permissions remain visible.

## Setup

Ask to set up the full profile while preserving existing content. The agent evaluates the full catalog, applies authorized eligible changes, reads them back and verifies repeated reconciliation. Project view CRUD uses supported APIs. Workflow/chart operations use available API methods or UI for unsupported configuration.

## Delivery

Ask to deliver an issue and maintain its Project, reviews, Wiki and release. The agent connects planning, branches, pull requests, checks, security, documentation and releases using repository-specific rules.

## Direct operation discovery

Use scripts/operations.py capabilities TERM, search TERM, describe OPERATION and type GRAPHQL_TYPE. [[API]] contains executable examples and registry maintenance instructions.

Full setup records each feature's configuration, applicability, access gate and evidence in GITHUB.md and its coverage ledger. Installation alone does not prove that all capabilities were configured.
