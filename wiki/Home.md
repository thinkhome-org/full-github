# Full GitHub

[Repository](https://github.com/thinkhome-org/full-github) · [Releases](https://github.com/thinkhome-org/full-github/releases) · [Project](https://github.com/orgs/thinkhome-org/projects/5)

Full GitHub brings source-backed GitHub capability discovery and execution into Codex.

## Start

Read [[Installation]] and [[Usage]], then browse [[Capabilities]] and [[API]]. [[Architecture]], [[Permissions]] and [[Verification]] explain how the plugin works and what was tested.

## Complete inventory

The 2026-11-15 snapshot contains 258 capability families, 1,281 published REST operations, 32 GraphQL queries, 285 mutations and 1,881 types. Deprecated and retired operations are identified explicitly. Repository, organization, enterprise and personal capabilities include their permission and plan boundaries.

Use the [complete operation directory](https://github.com/thinkhome-org/full-github/blob/main/docs/OPERATIONS.md) for searchable endpoint-level coverage.
