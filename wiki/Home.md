## Complete inventory

The 2026-11-15 snapshot contains 261 capability families, 1,281 published REST operations, 32 GraphQL queries, 285 mutations and 1,881 types. Deprecated and retired operations are identified explicitly. Repository, organization, enterprise and personal capabilities include their permission and plan boundaries.

Use the [complete operation directory](https://github.com/thinkhome-org/full-github/blob/main/docs/OPERATIONS.md) for searchable endpoint-level coverage.

The configuration guide records concrete option values, default policies, applicability, human interaction, recovery and verification. Full nested API definitions are bundled with the plugin, alongside current-source errata and qualified community incidents. Tagged release artifacts carry GitHub provenance and byte-verification evidence.
